# Introduction to LLD

## What is LLD?

LLD stands for **Low Level Design**.

It's the interview round that tests how well you can design the internal structure of a software component **at the class and object level**, as opposed to **HLD** (High Level Design / System Design), which deals with the big distributed systems.

## Why do interviewers ask it?

DSA rounds tell them you can solve algorithmic puzzles, but that's not what most of the job actually is.

Day to day, engineers design classes, define interfaces, and write code that other people will extend and maintain.

**LLD is a closer proxy for that real work.**

## Do you need to compile code?

Classic LLD rounds are discussion-style, often in a shared doc, and compilation is usually not required. The interviewer cares about your class design, relationships, and reasoning.

But some companies call it the **machine coding round** (ex: Flipkart, Swiggy, Razorpay), and working code is mandatory. You typically get **90–120 minutes** to write code that compiles, runs, and handles the requirements.
